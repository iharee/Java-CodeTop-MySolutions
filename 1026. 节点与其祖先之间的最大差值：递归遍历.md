题目简述：

> 给定二叉树的根节点 `root`，找出存在于 **不同** 节点 `A` 和 `B` 之间的最大值 `V`，其中 `V = |A.val - B.val|`，且 `A` 是 `B` 的祖先。
>
> （如果 A 的任何子节点之一为 B，或者 A 的任何子节点是 B 的祖先，那么我们认为 A 是 B 的祖先）

题目链接：[1026. 节点与其祖先之间的最大差值](https://leetcode.cn/problems/maximum-difference-between-node-and-ancestor/)

# 思路

当我们遍历所有节点，不同节点间的最大值必然存在于下面这样的情况：当前节点值减去子树的最大或最小值的绝对值。因此，定义递归函数 `dfs(root)` 分别返回子树的最大值或最小值，然后计算当前节点值减去子树最大值与最小值的差的绝对值，更新结果。

遍历的顺序是无关紧要的，前序遍历、后序遍历均可。

# 代码

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */

class Solution {

    private int res;

    public int maxAncestorDiff(TreeNode root) {
        res = 0;
        dfs(root);
        return res;
    }

    private int[] dfs(TreeNode root) {
        if (root == null) return null;
        int[] a = dfs(root.left);
        int[] b = dfs(root.right);
        int maxVal = root.val;
        int minVal = root.val;

        if (a != null) {
            maxVal = Math.max(maxVal, a[0]);
            minVal = Math.min(minVal, a[1]);
        }
        if (b != null) {
            maxVal = Math.max(maxVal, b[0]);
            minVal = Math.min(minVal, b[1]);
        }

        res = Math.max(Math.max(res, Math.abs(root.val - maxVal)), Math.abs(root.val - minVal));

        return new int[]{maxVal, minVal};
    }
}
```
